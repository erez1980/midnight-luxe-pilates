## המלצות להמשך

- להפעיל את migration ולבדוק חשבונות שונים ושיתוף אנונימי לפני פריסת תיקוני השיתוף.
- לבצע התחברות אמיתית עם Google, החלפת חשבון באותו דפדפן ועריכה בשני מכשירים, כולל חזרה לאחר ניתוק רשת.
- להשלים תוכן אמיתי לפי [הרשימה לרתם](retem-content-request.md). את הכפתור לאפליקציה יש לנסח סופית לפי קהל היעד.
- אם נדרשת מדידת פניות, לבחור כלי מדידה והגדרות פרטיות לפני הוספתו. לא הוטמע מעקב ללא בחירה כזו.
- עד לפריסת PR האמינות, הסנכרון הישן עדיין פעיל באתר. גרסת העיצוב נפרסת בנפרד ללא שינוי תהליך הסנכרון.

הוראות הפעלה ומגבלות נמצאות ב־[רשימת הפריסה](release-checklist.md).
